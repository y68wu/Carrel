# Carrel — A Campus Study Space Booking System

Carrel is a requirements-engineering portfolio for a campus study-space booking system. The seven deliverables trace the project from scope definition and stakeholder analysis through behavioral modeling, quality requirements, risk analysis, formal constraints, and requirements-engineering research.
